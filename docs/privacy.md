# 隐私与数据说明

## 原则

- 密码不持久化：登录密码只用于当次请求，成功后从 UI 状态清除；`StudentAccount` 不含密码字段。
- 会话令牌、题卡副本、历史、草稿、提交状态使用 Android Keystore 支持的 AES-GCM 加密后落盘。
- 所有账号相关数据按 `sha256(schoolId + "\0" + studentId)` 作用域隔离；切换账号会取消并丢弃
  过期加载，历史与缓存不串号。
- 不在运行日志、崩溃报告、测试输出、文档或交付包中写入真实账号、token、session、学生/学校 ID、
  答卷内容或其他真实用户记录。兼容协议所需的固定常量属于对应源码的一部分，不应当作安全凭据；
  报告和运行日志不展开其字面量。

## 本机保存的数据

| 数据 | 位置（逻辑） | 加密 | 生命周期 / 清除 |
|---|---|---|---|
| 已登录账号会话 | `encrypted_credentials` SharedPreferences | Keystore AES-GCM | 登出当前账号即移除；密码不保存 |
| 题卡离线副本 | `filesDir/template-cache/<scope+code hash>.json.enc` | Keystore AES-GCM | 设置页确认后清除；按账号+编号哈希命名，不暴露编号 |
| 最近访问历史 | `encrypted_history` | Keystore AES-GCM | 设置页确认后清除；最多 200 条/账号 |
| 作答草稿 | `encrypted_answer_drafts` | Keystore AES-GCM | 按账号+编号存储，确认成功后尝试清除；缓存清理不删除草稿 |
| 提交状态标记 | `encrypted_submission_state` | Keystore AES-GCM | 成功确认后移除；未知状态持久保留直到人工核实解锁 |
| 离线导入题库/目录 | `filesDir/offline-library-v2/cards/*.enc` 与 `index.enc` | 正文与元数据均为 Keystore AES-GCM | 用户可逐条删除或清空；旧 `encrypted_offline_library` 两键在新索引完整提交后才移除 |
| UI 偏好（主题） | `ui_preferences` | 非敏感明文 | 仅主题枚举，无凭据/业务数据 |

`allowBackup=false`：不参与系统备份/转移，避免加密数据被备份到不受控位置（同时意味着卸载
后数据不可恢复，卸载前请确认）。

## 网络与外发

- 二维码在**本机**通过 CameraX 取景 + ZXing Java core 3.5.3（`MultiFormatReader`）识别：CameraX
  的 Y plane 直接构建 `PlanarYUVLuminanceSource`，相册选图经有界采样后解码。ZXing 解码器本身是纯 Java，
  **无专有 ML Kit、无模型下载、无遥测**；CameraX / Compose 仍带有 native `.so` 依赖。
  不把二维码图片或识别结果上传到第三方服务；
  不再使用旧版 `2weima.com` 路径或其临时凭据。
- 上述为本机代码行为描述；**尚未在真实相机/权限场景实测**，不声称实际扫码成功。
- 登录、取题、图片上传、答卷提交连接 `www.xinjiaoyu.com`；提交前明确提示“图片先上传、答卷随后
  单独提交、不可撤回”。
- 题目图片与私有答卷图片使用 Coil 禁用内存与磁盘缓存，避免落入共享缓存目录；上传前对图片
  重编码并去除 EXIF。
- 应用不内置公共账号，不静默使用任何共享凭据；未登录不能查询新题卡或提交。
- 没有实现公告、学案下载、远端背景图、更新检查等会引入额外网络请求的旧/上游功能。

## 用户可控动作

- 设置页“清除在线缓存与历史”：二次确认后删除在线题卡加密缓存与最近访问记录，不退出账号、
  不撤回已提交答卷，也不删除草稿或未知提交标记。
- 设置页“清除离线资料库”：单独确认后删除导入题卡及目录；逐条删除也会确认，均不修改原始导入文件。
- 账号页“退出当前账号”：二次确认后移除当前账号会话；该账号的加密缓存仍保留，重新登录同一
  账号仍可读取。
- 提交页“已核实未提交，重新开放”：只在用户确认服务端未收到答卷后解除未知锁；仍需再次经过
  最终确认，应用不会自动查询服务端状态。

## 已知边界与不可承诺项

- 本机 Keystore 加密不等于端到端加密；已 root/已备份/同一设备上的其他有权应用不在威胁模型内。
- 无法自动迁移旧应用的私有数据；用户不应把旧 `setting.json`（含明文密码/token）复制到本应用
  或交给第三方。
- 导入的题卡只作离线阅读；其来源与授权由用户负责，本应用不校验其内容真实性。
- 本文描述的是当前源码设计；APK 实际行为、权限弹窗、加密是否在所有设备上生效尚未做真机验收。
