# 离线资料库（1.0.1）

## 整库导入

从 1.0.0 直接覆盖升级，保留已有题卡与本机加密密钥。打开“离线资料库 → 整库 ZIP”，选择此前提取的 `ZhiNengTiKa-offline-library-20261128T062800Z.zip`。无需解压、无需逐张选取。若此前已导入 100 张，整库导入会更新这些同编号题卡，补入另外 419 张，最终为 519 张，不生成 619 张重复副本。

原始提取包同时包含原始 JSON、规范 JSON 和阅读版。导入器优先使用 `题卡JSON/` 下的 519 份规范文件和 `科目目录/` 下的六科目录，不重复导入 `templateData/` 副本，不读取 HTML 和校验清单为题卡。也支持只有旧 `templateData/`、`templateList/` 的 ZIP，或一般 JSON 文件组成的 ZIP。压缩包直接读取，不向共享存储解压文件。

批量处理显示当前进度，只在整批结束反馈一次。原有的“仅供离线阅读、去除历史答卷”说明集中在页面底部，不再每张弹出。个别异常保留到“导入结果”，其余文件继续；取消或进程退出后可重新导入，同编号会更新。

## 科目和目录

顶部常驻“目录 / 题卡”、搜索框和六科筛选，顺序为语文、数学、英语、物理、化学、生物。全部科目默认显示分组概览，点击科目标题展开；选择单科或搜索时直接显示匹配内容。题卡导入后自动生成对应目录，目录不再排在数百张卡片之后。

显式导入科目优先；旧版 519 张题卡使用精确编号映射自动恢复分类，目录和路径标签、题名用于其他文件识别。原 `biography` 表示生物，`other` 显示为“未分类”，不会阻止自动识别。已导入 1.0.0 的 `other` 卡片在迁移时修复。未知且没有可靠科目信息的文件保留为“未分类”；可在“导入选项”选择科目后重新导入。

完整提取库的科目数量：语文 67、数学 101、英语 87、物理 111、化学 84、生物 69，共 519。这里只内置编号与科目映射；APK 不内置题干、答案、用户历史或旧题库正文。

## 存储与升级

题卡逐张使用 Android Keystore AES-GCM 加密，索引元数据和目录也加密。列表只解密轻量索引，打开题卡只读取该卡正文。更新同编号保留原有本机 ID；新增题卡不会重写其他题卡正文。索引发布前发生错误会保留旧数据，重启可清理未提交临时文件。

1.0.0 的两个 SharedPreferences 键先完整解密，迁移并同步提交全部题卡、目录与完成标记后才删除。中断可重新迁移；清理旧键失败不会再次合并或复活已清空的资料。

当前容量：10,000 张题卡、总题卡 JSON 512 MiB、10,000 条目录；单份 JSON/目录仍不超过 8 MiB。ZIP 文件不超过 128 MiB，被选中的解压内容合计不超过 256 MiB。目录重复项与同编号更新按去重后的实际容量计算。

题库原图仍然是外部链接，没有打包在旧 APK 中；本次不下载图片、不修改阅读器富文本能力。原生离线阅读仍不请求远端图片，复杂 MathML 排版限制保持，完整浏览器阅读版可从提取包打开。

## 开发验证

```sh
python3 tools/build-android.py -- :protocol:test
python3 tools/build-android.py -- :protocol:verifyOfflineLibrary \
  -PofflineLibraryZip=/path/to/ZhiNengTiKa-offline-library-20261128T062800Z.zip
```

整库验收使用产品导入器和文件引擎，并在主机 JVM 上以 AES-GCM 实际加密落盘。它验证旧 100 张迁移、419 新增 / 100 更新、重启后 519 张与 7,355 道题可读、六科目录各数量、重复导入零新增、原 ID 保留，以及列表不解密卡片正文。结果写到 `protocol/build/reports/offline-library-verification.json`。

单元回归另覆盖 2,001 张、容量更新、原子写失败、迁移中断与清理失败、ZIP 路径/大小限制和批次反馈。主机验收不能代替 Android Keystore、SAF 文件提供方及真机 UI；每次交付的实际执行范围见验收报告。
