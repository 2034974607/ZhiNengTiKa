# 功能对照：旧版与 2026 原生重写版

## 状态与证据范围

本文对照 fork 修复版 1.8.1（`ed34415`，Qt Widgets + Android QtWebView/QML 壳）、upstream `dev` 快照（`4d192e4`，Qt Widgets + QML 双前端）和本仓库的原生重写版。旧版事实来自[第一阶段业务审计](audit/features.md)，固定提交记录见[仓库基线](audit/repository-baseline.json)。

当前功能已接入源码，并实际生成最终 Debug、独立签名且经 R8/资源收缩的 Release，以及 Debug instrumentation 测试 APK；三个最终 APK 均通过签名、包名/版本、最低 API 26 / 目标 API 35、ZIP 完整性和对齐检查。最后一轮草稿、权限、主题、备份声明与相册重选提示已编入这些产物。

JVM 合成测试实际执行 **32 项，全部通过**；两个 Compose instrumentation 测试已编译，尚未在设备执行。没有安装、启动、真实界面操作或生产 API 请求，也没有相机/系统权限/真实账号验收。构建与静态检查不能证明所有设备路径或现行服务端协议可用；详见[测试报告](../TESTING.md)及[已知问题](known-issues.md)。

## 总体范围

原生版是在 AGPLv3 下独立重写的 Kotlin / Jetpack Compose / Material 3 客户端，不依赖 Qt、QML 或 WebView。保留学生登录、按编号查询、题卡阅读、选择题和主观题作答、图片上传及答卷提交；新增本机只读资料库、SAF 导入导出、账号隔离的加密草稿和持久未知提交保护。它尚不具备旧版全部功能的等价替换能力。

| 编号查询 | 内置资源 → 缓存 → 服务端 | 学科列表与 UserHistory | 首页手输编号查询；先请求网络，符合条件的网络错误回退到当前账号加密缓存；未登录不能查询新题卡，不内置旧题库 |
| 名称与目录搜索 | 搜索内置 all 列表 | 静态列表与 UserHistory | 首页按历史题名/编号筛选；离线库按题名/编号/学科搜索并提供学科筛选；范围是本机历史及用户导入内容 |
| 二维码 | 拍照/选图上传第三方 `2weima.com` | ZXing-C++ 实时取景/选图，本地解码 | CameraX + ZXing Java core 3.5.3，本机解码实时帧或降采样后的相册图片；可切摄像头，授权由用户触发；扫码只回填编号供核对，不自动提交。尚未相机实测 |
| 全部/逐题阅读 | 答案解析与 Only Answer；原题可显示答案 | 解析/答案/原题、All | 在线详情为全部/解析/答案/原题/作业五页；离线详情为前四页。全部页使用 LazyColumn；逐题保留父题上下文和递归子题；解析和原题有答案显示开关 |
| 富文本与题图 | WebView/QML 富文本 | QML 富文本与异步图片 | Android TextView 的受限 HTML 与独立 HTTPS 图片显示；不执行脚本，不支持完整 CSS、MathML 或 JavaScript 公式排版，复杂内容可能与旧版不同 |
| 作业作答 | 单/多选、图片题、答案回填、原始 JSON 编辑、确认提交 | 新版两个前端均无提交入口 | 保留单/多选、每题最多八张图片、参考答案/上次答卷回填确认、未答提醒和目标账号/不可撤回确认；图片先上传，答卷单独发送；不提供原始答卷 JSON 手工编辑 |
| 提交保护 | 同步请求，固定响应全文判断成功 | 无提交路径 | 持久加密 UNKNOWN journal、原子占位、进程内在途保护；冻结确认快照；禁用重定向和连接重试、一次性 POST；实际终止回调或同步构造失败释放内存保护，未知标记保留至明确成功或人工核实；不自动重试 |
| 草稿与照片权限 | 主要为 UI 临时状态 | 无独立持久草稿 | 按账号/题卡加密保存；草稿加载完成才启用作答。去抖保存、返回与生命周期停止时刷新写入共用 Mutex；返回时等待保存，失败可重试或明确选择不保存离开；相册 URI 取得持久读取权限后才存入草稿。页面重建后丢失选图上下文会显示重选提示；这些恢复路径尚未真机执行 |

ZXing 解码器本身是纯 Java，不依赖专有 ML Kit、模型下载或遥测；传递依赖 CameraX / Compose 仍带有 `.so`。最终 APK 的原生库 16 KiB ELF/ZIP 对齐已验证，不能据此推断相机或 16 KiB 设备运行通过。依赖许可及构件来源见[第三方声明](third-party-notices.md)，构建方式见[构建说明](../BUILDING.md)。

## 账号与数据迁移差异

公共账号会话不属于可再分发的稳定授权资产，新版要求使用自己的学生账号。Android 沙箱阻止新包直接读取旧应用私有配置、缓存和历史；本版没有自动迁移通道。用户可自行导入有权使用的题卡或目录，导入结果始终只读，不导入旧密码、token 或作答授权。

旧题库、学科列表与微软雅黑字体的再分发许可未澄清，因此未随包提供。上游远端背景、公告、资源 API、旧更新源及字体偏好也未自动迁移。完整范围见[迁移说明](migration.md)与[第一阶段许可审计](audit/toolchain-licenses.md)。

## 验证仍需补齐的部分

最终重建与最终 APK 复核结果应以[测试报告](../TESTING.md)及交付证据为准。两个 instrumentation 测试从未执行；实际安装、后台/旋转恢复、相册 URI 恢复、相机、系统选择器、权限和所有真实 API 路径均未验证。已记录的是主机 JVM 合成数据测量，不能替代 Android 启动、帧率、内存、功耗或 Qt 同条件对比，见[性能报告](../PERFORMANCE.md)。
