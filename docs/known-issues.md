## Lint 与构建工具链限制

首轮 Lint 发现 API 27 的 `windowLightNavigationBar` 被放在最低 API 26 的基础主题中，已改为 `values-v27` 资源；同时加入 Android 12+ `dataExtractionRules` 和旧系统 `fullBackupContent="false"`，排除云备份和设备迁移。该修正未通过关闭 NewApi 检查或添加错误 baseline 实现，最终 Debug / Release Lint 均无错误。

Navigation 2.8.9 随附的三个自定义 Lint 注册器与当前 Lint API 不兼容，报告 `ObsoleteLintCustomCheck` 并跳过相关规则，包括部分路由、start destination、序列化/Keep 注解和 Compose 导航作用域检查。其他 Lint 检查实际运行并发现了上述主题错误；不能写作“所有规则完整覆盖”。本轮不做整体框架升级，保留原始警告作为分析覆盖限制。

官方 SDK 目录曾被 AGP 自动下载 x86 platform-tools 37.0.3，未执行它；已设置 `android.builder.sdkDownload=false`。本机使用显式覆盖的第三方静态 ARM64 aapt2，已验证架构并实际执行，但该二进制未由本项目独立重建。Release R8 产包成功不证明反射、序列化、资源和所有运行路径正确。

## 服务端互操作

协议依据两个旧仓库静态审计实现，没有向 `www.xinjiaoyu.com` 发出真实业务请求，也没有使用真实账号。现行登录、题卡、图片上传、答卷提交的字段、权限、业务码和 URL 规则仍未知。AES 往返与固定 MD5 向量只证明本地算法行为，缺少经授权的脱敏服务端密文夹具作跨实现验证。

网络层禁用自动重定向和连接失败重试，提交与上传使用一次性请求体；HTTP 503、重定向、取消和同步构造失败等使用 MockWebServer 合成测试验证。它不能替代真实 TLS、弱网、服务端事务及幂等规则验收，详见[协议说明](protocol.md)。

## 不可逆提交与持久状态

- “结果未知”不能等同于失败。未知标记经加密持久保存，不自动重试；只能在用户到服务端人工核实后考虑解锁，本应用无法查询服务端提交状态。
- 确认时冻结作答快照，草稿加载及提交状态检查完成后才启用作答/提交；提交期间禁用编辑。进程内在途保护由真实 Call 终止或同步构造失败释放，尚未交给网络的占位在退出时释放内存保护，持久未知标记仍保留。
- 图片上传和答卷提交是两个事务。图片上传成功但答卷失败可能留下服务端孤立文件，当前不删除、不自动重试；其清理和幂等能力未经服务端确认。
- 进程死亡会结束内存保护，但不会清除已写入的 UNKNOWN journal；再次启动仍需核实。进程终止、磁盘故障、快速退出和后台恢复的实际行为尚未设备测试。

## 已实现功能的设备验证范围

当前源码已实现只读资料库、JSON/目录导入、题名/编号/学科搜索、首页历史过滤、合成示例、ALL 与逐题阅读、在线/离线 HTML 导出、三种主题、动态许可全文对话框、分级数据清理与确认删除。

导入/演示题卡不传账号，无作业页，禁止上传/提交且不请求远端题图。离线库及详情从 IO 读取，解密/存储失败显示错误；保存时在锁内检查容量。它仍将整库作为加密 blob 重写，接近总容量上限时可能较慢；单文件 8 MiB、100 张卡/16 MiB 总题卡 JSON、10,000 条目录是设计限制。

草稿实现去抖保存、返回/生命周期停止时刷新、写入 Mutex 和失败提示；相册 URI 成功取得持久读取权限后才保存。打开相册期间若页面重建而丢失题目上下文，返回的选择会显示“请重新选择图片”对话框，不会静默丢弃或附到其他题目；当前需要用户重新选择，不承诺自动恢复这次选择。尚未验证快速返回、旋转、后台被杀、系统照片提供方恢复等场景，不能承诺进程突然死亡前的最后操作必然落盘。持久 URI 权限也不能恢复已被删除的原图或被提供方撤销的访问。

上述功能的系统选择器、取消、错误恢复、主题与大字体布局、真实触控、权限拒绝和设备兼容均未执行。二维码代码为 CameraX + ZXing Java core 3.5.3，本机解码；ZXing 自身为纯 Java，但 CameraX / Compose 的传递依赖仍包含 `.so`，不能写成 APK 无 native 库。二维码识别和切镜头尚未相机实测，16 KiB 对齐通过也不代表该类设备已运行通过。

## 富文本与导出限制

原生 TextView 只支持受限 HTML，不执行 JavaScript，不支持完整 CSS、MathML 或浏览器公式排版。复杂公式、表格、样式及图片位置可能与旧 WebView/QML 不同，当前没有真实题卡截图或逐题等价性比较。

应用内只对允许的在线内容请求 HTTPS 图片；离线导入内容不请求远端题图。HTML 导出经净化且不含历史答卷，但图片仍是 HTTPS 引用，不是包含图片的离线归档；外部浏览器可能请求远端资源。导出文件由用户选择的文档提供方保存，不自动加密。

## 隐私、许可与性能边界

Keystore AES-GCM 保护应用私有静态数据，不等于端到端加密，也不能防止已取得系统级权限的攻击。密码不持久化；协议内置对称密钥不构成安全边界。备份/迁移排除配置意味着不能依赖系统恢复本版私有加密数据。私有图片禁用 Coil 缓存，上传重编码去 EXIF，不删除或修改用户相册原图。

项目以 AGPLv3 分发，第三方组件保留原许可；JUnit 4.13.2 是测试依赖，许可为 EPL 1.0。许可全文与实际构件声明可从设置页查看，但构件许可提取并不等于完整法律审查，详见[第三方声明](third-party-notices.md)。

已有一次主机 JVM 合成数据路径测量和最终 APK 实际字节大小；Release 2,708,694 字节，Debug 22,115,366 字节，测试 APK 1,056,109 字节。尚无 Android 冷/热启动、帧时间、PSS、功耗、温升或真实上传耗时，也没有同条件 Qt 对比，不能声称性能提升；原始范围与异常值见[性能报告](../PERFORMANCE.md)。
